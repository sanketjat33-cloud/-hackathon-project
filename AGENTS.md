# Agrova Frontend Development Rules

## Project
Agrova is a smart agriculture platform connecting farmers and wholesalers.

## Stack
- React
- Vite
- JavaScript
- Tailwind CSS
- React Router
- Lucide React

## Architecture

Use:
- src/pages for complete screens
- src/components for reusable UI components
- src/data for static/mock data
- src/assets for images and static assets
- src/layouts for shared page layouts

## Rules

1. Build one feature/page at a time.
2. Do not put the entire application inside App.jsx.
3. Prefer reusable components.
4. Do not install unnecessary packages.
5. Keep components small and understandable.
6. Use semantic HTML.
7. Make the UI responsive.
8. Match the Stitch design closely.
9. Do not change unrelated files.
10. Do not create backend code yet.
11. Use mock data where backend data is not available.
12. Keep farmer and wholesaler functionality modular.
13. Use accessible buttons and form controls.
14. Maintain consistent Agrova colors, spacing, typography and border radius.
15. Before changing existing code, inspect the current implementation.
